## ⚡ About

QuickSQL helps you practice SQL and run queries in a clean, mobile-friendly experience.  
It includes a browser experience plus a React Native Android app focused on learning and quick experimentation.

## ✨ Highlights

- 🧠 **Practice-friendly SQL workflow** with fast query execution
- 🗂️ **Tables & attributes explorer** for easier schema navigation
- 🧾 **Query history and multi-tab editor style flow**
- 🌗 **Dark/light friendly UI** designed for long usage
- 📱 **Android-ready build pipeline** with release APK support

## 🚀 Installation (Android)

1. Open the [latest release](https://github.com/VasiKumar/Vasi_QuickSQL/releases/latest).
2. Download the `.apk` file.
3. Open it on your Android device.
4. If prompted, allow install permissions for that source.
5. Install and launch QuickSQL.

> Only install APKs you trust.

## 🛠️ Tech Stack

- **Web:** React 19, TypeScript, Vite
- **Mobile:** React Native (Android), Expo tooling
- **Query Engine:** SQL execution + PostgreSQL-oriented workflow

## 🧪 Local Development (Web)

```bash
npm install
npm run dev
```
